# 指令库

本仓库的口令总表。新指令不以聊天宣布为准，必须以 `超级指令.json` 新增或更新的条目为准。

来源：用户交来的《\*超级指令.docx》（从 NuwaSkill-Yao 口令总表收录）。原件保存在 `来源-超级指令.docx`。本目录是录入后的指令库。

## 文件

- `*超级指令.docx`：给人看的总表
- `超级指令.json`：数据源
- `登记指令.py`：按 keyword upsert
- `更新超级指令.py`：重写 DOCX
- `来源-超级指令.docx`：首次收录的原件

## 自动更新

```bash
python3 files/指令库/登记指令.py \
  --keyword "新口令" \
  --type "关键词口令" \
  --purpose "一句话用途" \
  --inputs "需要用户提供什么" \
  --operation "逐步做什么" \
  --outputs "生成哪些文件"
```

## 本仓库正在用的口令

- **收录案例文章**：原版 PDF + 原版 DOCX + 分类好文段组；图进 `files/案例文章/备份N/`。给别人看的交互页是 HTML，不是 Markdown，也不是仅限 Cursor 的画布。
- **对话分组的事实与观点**：把 OCR 对话分成事实 / 观点等组；对外用自包含 HTML

1–10 条是收录进来的姚勇文章口令，路径仍指向原仓库习惯，本仓库没有 `files/YaoZHIhu/`。不要在本仓库执行 1–10，除非用户把那套文件也迁过来。
