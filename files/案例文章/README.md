# 案例文章

口令：**收录案例文章**

模仿「收录姚勇文章」，但本仓库要的是三件套，不是只出一篇 DOCX。

## 每篇三件套

1. **原版 PDF**：截图原样入页，不重排
2. **原版 DOCX**：著录、缺项、OCR、评论原图
3. **分类好文段组 DOCX**（另有 Markdown）：默认按事实与观点分组

分类文段必须给**可修改链接**。Cursor 里用 Canvas；仓库里改 `01分类好文段-事实与观点.md` 或 `案例数据.json`。

## 备份

原图按收到顺序进 `备份N/`。第一次就是 `备份1/`。不覆盖旧备份。

## 目录

`案例文章目录/` 里有 `案例目录.json` 和生成脚本。收录完跑：

```bash
python3 files/案例文章/案例文章目录/生成案例三件套.py
python3 files/案例文章/案例文章目录/更新案例文章目录.py
```

## 和姚勇口令的差别

姚勇口令：评论只贴图，不 OCR 进正文。  
本口令：案例评论要先 OCR，才能做「对话分组的事实与观点」。原图仍要贴进原版 DOCX。
