# 案例文章

口令：**收录案例文章**

模仿「收录姚勇文章」，但本仓库要的是三件套，不是只出一篇 DOCX。

## 每篇三件套

1. **原版 PDF**：截图原样入页，不重排
2. **原版 DOCX**：著录、缺项、OCR、评论原图
3. **分类好文段组 DOCX**（另有 Markdown）：默认按事实与观点分组

分类文段必须给**可修改链接**。给别人看用 **HTML**（任何浏览器）。Cursor 里的 Canvas 只是同内容的编辑器，对没有 Cursor 的人不友好。仓库里还有 Markdown / JSON 归档，那些没有下拉选项。说明见 `分类页-载体说明.md`。

## 备份

原图按收到顺序进 `备份N/`。第一次就是 `备份1/`。不覆盖旧备份。

- `备份1/`：两张窄评论图（01 原版 PDF 的来源）
- `备份2/`：知乎「79 条回复」高清滚动截图 图01–图13
- `备份3/`：知乎回答页 FireShot PDF

## 讲解稿

同一话题三份，编号对应讨论轮次：

| 版本 | 文件 | 形态 |
| --- | --- | --- |
| **V1** | `V1-珠三角没人鸟你-地方财政结构解释.pptx`（同名 `.pdf`） | 11 页讲解 PPT，适合放映 |
| **V2-1** | `V2-1-没人鸟你-公司与个人的找茬.pdf`（同名 `.docx`） | A / B / C 三问逐条回答，2 页 |
| **V2-2** | `V2-2-地方财政结构-原因的原因.pdf`（同名 `.docx`） | 税基结构 + 四层成因 + 反例，2 页 |

V2 的 `.docx` 是可改稿，改完重跑脚本即重出 PDF：

```bash
python3 files/案例文章/生成PPT-没人鸟你.py        # V1
python3 files/案例文章/生成讲解PDF-V2.py          # V2-1 / V2-2
```

## 目录

`案例文章目录/` 里有 `案例目录.json` 和生成脚本。收录完跑：

```bash
python3 files/案例文章/案例文章目录/生成案例三件套.py
python3 files/案例文章/案例文章目录/更新案例文章目录.py
```

## 和姚勇口令的差别

姚勇口令：评论只贴图，不 OCR 进正文。  
本口令：案例评论要先 OCR，才能做「对话分组的事实与观点」。原图仍要贴进原版 DOCX。
