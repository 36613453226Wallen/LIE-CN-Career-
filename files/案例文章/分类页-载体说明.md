# 分类页是什么载体

截图里带「全部 / 事实 / 观点」选项的那一页**不是 Markdown**。Markdown 只能排静态文字，做不出下拉和筛选。

## 现在有三层，不是一种文件

| 层 | 文件 / 界面 | 谁能看 | 有没有选项 |
| --- | --- | --- | --- |
| 交互页（给别人看） | `01分类好文段-事实与观点.html` | 任何浏览器 | 有筛选、改类别 |
| Cursor 画布 | Canvas（React） | 主要在 Cursor 里 | 有，但不适合给外人 |
| 归档 | `.md` `.docx` `案例数据.json` | GitHub / Word | 无选项，只是文稿和数据 |

**给需要展示的用户：发 HTML，或让对方下载后双击用浏览器打开。** 不要只发 Canvas 链接。

数据源是 `案例数据.json`。HTML 生成时把 JSON **写进网页内部**，所以单文件就能开，不靠联网、不靠 Cursor。

## 你看到的 Cursor 页是怎么做的

那是 **Cursor Canvas**：一份只存在 Cursor 里的 React 单页，不是仓库里的 `.md`。

- 写法：一个 `.canvas.tsx` 组件
- 组件库：`cursor/canvas`（`Pill` 筛选、`Table` 表、`Select` 改类别、`TextArea` 改原文、`useCanvasState` 把改动记在画布旁）
- 限制：别人没有这个对话/这个 Cursor 账号时，页面不友好。GitHub 上也看不到这个 React 源码。

## 现在补上的 HTML 是怎么做的

- 技术：一份 **HTML + CSS + 原生 JavaScript**，没有 React、没有打包、没有服务器
- 工具：`生成案例三件套.py` 读 `案例数据.json` 写出 `.html`
- 浏览器里改分类会进 **localStorage**（只在这台电脑的浏览器里），不会自动写回 Git

别人要看时：

1. 下载 `01分类好文段-事实与观点.html`，用 Chrome / Edge / Safari 打开
2. 或把文件放到任意静态网页空间（GitHub Pages、网盘、自己的站点）
3. GitHub 的文件页默认显示源码，**不能直接当网页点开**；需要 Pages，或把文件发出去

## 不要用的误解

- 不是「md 里嵌了选项」
- 不是 Word 宏
- 不是必须部署的复杂前后端。一份 HTML 就够展示
